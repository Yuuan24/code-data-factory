# Interaction and Training Consumer Contract

**Version**: 2.0.0 | **Status**: planned；接口/回执尚未实现。
对应 FR-006–014、031–037 与 SC-011–013。强化学习（RL）消费资格按具体框架和版本判定。

## Shared Task Interface

这是本项目任务包对外暴露的最小语义，不要求重新实现上游 Agent（智能体）循环。

| 操作 | 输入 | 输出与规则 |
|---|---|---|
| `open_task` | 已冻结 task 引用、预算、尝试标识 | 独立会话、模型可见初始观察、工具定义、能力声明；隐藏参考不返回 |
| `execute_tool` | 会话、call_id、工具名、已校验参数 | 原始结果引用、模型可见结果、状态、耗时；同 call_id 重试不能静默重复副作用 |
| `record_model_call` | 实际可见输入、原始输出、可用词元及策略身份 | 成对事件和 context 引用；不根据最终 messages 倒推请求 |
| `close_attempt` | 结束原因、最终模型输出、最后完整事件 | 不可变尝试清单；预算截断不能伪装正常结束 |
| `verify_attempt` | 已封存尝试、验证器版本、私有参考 | 独立检查明细、PASS/FAIL/UNKNOWN；不给模型作为普通工具返回 |
| `score_evidence` | 已有验证/证据、奖励策略版本 | 新奖励记录；不产生新的工具执行记录 |
| `save_state` / `restore_state` | 具备能力的会话/快照引用 | 新尝试、父引用、分支位置；不支持返回 `UNSUPPORTED_CAPABILITY` |

以上操作实现为包内函数及薄适配，不要求 HTTP（超文本传输协议）服务。
实际工具 bundle（工具集合）为 `search_documents`、`read_document`、`calculate`、`convert`。
smolagents 的终答动作与训练器直接文本结束的协议差异由适配层记录，不更改任务完成标准。

## First-Version smolagents Adapter

- 使用 `ToolCallingAgent`，关闭隐式规划/额外基础工具，显式提供工具和固定提示模板。
- 模型包装器在网络/本地模型调用边界记录请求与输出，`step_callbacks` 补充工具/步骤结果；不能
  以 `replay()` 打印或整理后的 memory（交互记忆）证明精确上下文。
- 所有模型调用（含框架强制终答）、工具调用（含批量）均计入总预算。硬预算守卫必须在调用前检查；
  步数用尽后的框架额外终答若无法阻止，适配门禁失败，不能当免费额外推理。
- 工具仅处理通过模式校验的参数；不把公开轨迹中的文本作为代码执行。
- 同任务多次尝试隔离会话；原始失败与恢复保留，最终正确不自动批准所有中间动作作示范。

## First-Version TRL Adapter

TRL 为现成训练库。首版提供一个环境工厂映射，不调用 RL 优化器：

- `reset(**task_fields)` 映射到任务复位；只向模型公开四个工具方法。
- 验证、评分、快照、结束和辅助方法保持私有或在环境对象外，防止被自动发现为模型工具。
- 上游负责生成/解析/多轮循环；奖励回调从 completion（完整输出）与环境记录联合构造封存尝试，
  调用同一验证器。环境工具执行返回本身不得当作最终正确性。
- 原始采样词元与模型输出 mask（逐词元来源标记）由真实生成接口采集；不得从重新格式化消息
  反向补写。`input_ids`、`output_ids`、对应长度及模型身份需可核对。
- 非模型产生的工具观察不作策略动作训练；模型采样产生的控制/结束词元保留。未来算法需要的
  生成概率由真实采样器按 consumer profile（消费者字段与语义要求）提供。
- 对未知奖励返回明确不可训练状态，由适配层剔除并计数，不能让上游默认求和把未知视为零。
- 未解决上下文重写、跨版本策略或缺少词元附件的轨迹拒绝当前消费者资格；不影响合规 SFT 用途。

如果实际版本的环境工厂无法提供必要采样证据，先验证其 `rollout_func`（自定义采样回调）接口，
由上游采样调用返回词元；扩展只补数据采集，不复制优化器或通用 Agent 运行时。无法完成时兼容
门禁为失败，不能靠测试替身签发真实采样回执。

## Three Different Replay Operations and Rescoring

| 模式 | 是否新执行动作 | 是否重新生成模型输出 | 可证明什么 |
|---|---:|---:|---|
| 历史日志回看 | 否 | 否 | 记录可读与关联完整 |
| 固定动作重新执行 | 是 | 否 | 冻结环境下同动作可复验 |
| 模型重新采样 | 是 | 是 | 当前模型在当前观察上的真实行为 |
| 固定证据重新评分 | 否 | 否 | 判定/奖励版本变化的影响 |

历史服务缺少初始状态只能完成第一类；用本地替代工具生成的新任务不得称为原环境重放。

## Required Compatibility Matrix

| 检查 | 固定输入 | 必须输出 | 证据边界 |
|---|---|---|---|
| 双入口环境语义 | 相同任务与相同脚本动作，两入口各一次 | 工具结果、状态和独立判定相同 | 环境契约，不是随机策略一致性 |
| 真实采样 | 至少两任务各两次，冻结模型与采样参数 | 原词元、实际上下文、输出 mask、策略/模板/依赖版本、所有终态 | 真实采样，无参数更新 |
| 缺字段拒绝 | 无词元的历史样本、伪采样身份、错误长度 | 消费拒绝及原因 | 不影响符合规则的历史 SFT |
| 长程结构 | 32/128 步各一，含跨步取值和大观察引用 | 顺序、关联、长度无损；资源使用与读取耗时 | 固定案例，不证明模型长程能力 |
| 上下文改写 | 原观察、可见截断、一次摘要替换 | 前后 context、改写原因与训练兼容状态 | 能记录不等于支持所有 RL 损失策略 |
| 受控恢复 | 固定只读语料、会话工作区的中断快照 | 父/子尝试、分支点、恢复后相同固定动作结果 | 只对声明支持的环境有效 |
| 不支持恢复 | 含不可恢复外部状态的案例 | 明确 unsupported，不退化为日志打印 | 不声称通用环境重建 |
| 稀疏奖励 | 成功、已知全零、未知、截断各至少 2 个任务 | 按任务/尝试两层对账；两个奖励版本重评分差异 | 不自动把质检变过程奖励 |

## Acceptance and Future Extension

首版回执须列上游版本、任务/环境/验证器哈希、真实运行引用和未支持能力。软件接口通过与真实采样
通过分开，不用一个 RL-ready 布尔字段概括。没有采样资源时该验收未完成。

未来 RL 阶段新增优化配置、权重同步、算法元数据与独立预算，交给成熟训练器；复用上述任务/验证
接口、原始事件与数据治理。长程阶段增加任务分布、环境专用状态和上下文策略；状态扩展挂在带模式
版本的产物引用上，禁止在每个事件塞入无法校验的任意扩展字典。
